# ⚔️ 로스트아크 품앗이 레이드 매칭 Discord 봇

길드원들의 캐릭터 정보를 자동으로 수집하고, 레이드 규칙에 맞는 최적의 파티 조합을 구성해주는 Discord 봇입니다.

---

## 주요 기능

- 로스트아크 OpenAPI를 통해 캐릭터 정보 자동 수집
- 직업별 역할(딜러 / 서폿 / 딜폿) 및 사멸/비사멸 설정
- 서폿 배치, 직업 중복, 사멸 시너지 등 레이드 규칙을 반영한 파티 자동 구성
- 서버(길드)별 독립적인 데이터 관리

---

## 사전 준비

### 필요한 것

- Python 3.10 이상
- Discord 봇 토큰 ([Discord Developer Portal](https://discord.com/developers/applications))

## 봇 사용 방법

### `/등록` — 캐릭터 등록

본인의 대표 캐릭터명을 입력하면, 연결된 캐릭터 전체를 자동으로 불러와 등록합니다.

```
/등록 대표캐릭명: 홍길동
```

등록 후 버튼이 표시됩니다:
- **서폿 직업** (바드, 도화가, 홀리나이트, 발키리): 버튼을 눌러 `딜러 → 서폿 → 딜폿` 순으로 역할 전환
- **홀리나이트 (딜러/딜폿 모드)**: 사멸/비사멸 추가 선택 가능
- **사멸/비사멸 선택 직업** (브레이커, 가디언나이트): 사멸 여부 토글
- 설정 완료 후 **설정 완료** 버튼 클릭

> 아이템 레벨 1640 미만 캐릭터는 자동으로 제외됩니다.

---

### `/품앗이매칭` — 레이드 파티 구성

레이드 종류와 판수를 선택한 뒤, 이번 품앗이에 참여할 길드원을 고릅니다.

```
/품앗이매칭 raid: 모르둠 하드 판수: 4
```

1. 레이드 종류와 판수 입력
2. 드롭다운에서 참여 길드원 선택 (복수 선택 가능)
3. 자동으로 최적 파티 조합 출력

**파티 구성 규칙:**
- 파티당 서폿/딜폿 최소 1명
- 같은 파티 내 동일 유저 중복 불가
- 같은 파티 내 `(직업, 역할)` 중복 불가
- 8인 레이드: 길드원 4명이 파티 절반 구성, 나머지 4명은 공개 모집
- 사멸 시너지(워로드·블레이드) 우선 고려한 파티 배치

**지원 레이드:**

| 세르카 하드 | 1730 | 4인 |
| 세르카 노말 | 1710 | 4인 |
| 종막 하드 | 1730 | 8인 |

## 알고리즘 설명

백트래킹(Backtracking) 방식으로 전체 라운드에 걸쳐 유효한 파티 조합을 탐색합니다.

1. **캐릭터 풀 구성**: 참여 길드원의 캐릭터 중 해당 레이드 최소 레벨 이상인 것만 선별
2. **라운드별 탐색**: 풀에서 `라운드당 필요 인원`을 조합으로 뽑아 유효성 검사
3. **파티 분할 (8인)**: 8인 조합을 두 파티로 나눌 때 시너지 점수가 가장 높은 분할 선택
4. **재귀 탐색**: 사용된 캐릭터를 풀에서 제거하고 다음 라운드 탐색 반복

**파티 유효성 조건:**
- 파티 내 동일 유저 중복 없음
- 서폿/딜폿 최소 1명
- `(직업, 역할)` 튜플 중복 없음

**시너지 점수 계산:**
- 워로드 또는 블레이드가 있는 파티에 사멸 딜러가 많을수록 가산점

## 테스트용 DB 시딩 (개발자용)

길드원들이 직접 `/등록`하기 전에 테스트하려면 `seed_members.py`를 활용하세요.

1. `src/seed_members.py` 열기
2. `TEST_GUILD_ID`에 Discord 서버 ID 입력
3. `MAIN_CHARS` 리스트에 대표 캐릭터명 입력
4. 실행:

```bash
cd src
python seed_members.py
```

> Discord 서버 ID 확인: Discord 설정 → 고급 → 개발자 모드 활성화 후, 서버 우클릭 → **서버 ID 복사**
